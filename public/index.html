Step 1: Open the agent URL on your mobile device

Step 2: Allow camera, location, and file access permissions

Camera, location aur file access ki permission allow karein

Step 3: Give your device a name

Step 4: Click "Connect Device" button

"Connect Device" button dabayein

Step 5: Your device will appear in the dashboard

Aapka device dashboard mein dikh jayega
